`seanum` is an attribute macro — generated by `megamac!(kind = Attr, name = seanum, doc = "readme")` — that generates a SeaORM `ActiveEnum` from a plain Rust enum. Crate path: `rsmack_seanum` (facade: `rsmack::seanum`, feature `seanum`).

## Signature

```rust
#[seanum(
    rs_type = "String",
    db_type = "String(sea_orm::sea_query::StringLen::None)",
    rename_all = "snake_case",
    derives("::serde::Serialize", "::serde::Deserialize")
)]
pub enum SwitchAction { ... }
```

## Item arguments

### rs_type :badge[required]

- **Type:** `syn::Ident`
- **Meaning:** the Rust type of the enum values (`"String"`, `"i32"`, ...)

### db_type :badge[required]

- **Type:** string literal
- **Meaning:** the SeaORM column type, passed through to `#[sea_orm(rs_type = ..., db_type = ...)]`

### derives :badge[optional]{variant="note"}

- **Type:** list of string literals, parsed as paths
- **Default:** empty
- **Meaning:** extra derives appended after the defaults; invalid entries report `Invalid 'derives' entry: {e}`

### migration :badge[optional]{variant="note"}

- **Type:** `bool`
- **Default:** `false`
- **Meaning:** generates a `migration_column_def()` helper for `sea-orm-migration`

### rename_all :badge[optional]{variant="note"}

- **Type:** string literal — one of `snake_case`, `camelCase`, `PascalCase`, `kebab-case`, `SCREAMING_SNAKE_CASE`, `lowercase`, `UPPERCASE`
- **Default:** none — values keep their Rust names
- **Meaning:** normalizes every non-renamed value; an unknown case is fatal

### enum_name :badge[optional]{variant="note"}

- **Type:** string literal
- **Default:** the snake-cased enum name
- **Meaning:** overrides the table name passed to `#[sea_orm(enum_name = ...)]`

## Variant arguments

### rename :badge[optional]{variant="note"}

- **Type:** string literal on a variant: `#[seanum(rename = "send_email")]`
- **Meaning:** overrides `rename_all` for that variant; consumed from the output

## Default derives

`Clone`, `Debug`, `PartialEq`, `Eq`, `Hash`, `::sea_orm::EnumIter`, `::sea_orm::DeriveActiveEnum` — minimal by design; `serde`/`fake` are opt-in through `derives(...)`, never hidden dependencies.

## Integer rs_type behavior

When `rs_type` is one of `i8`–`i64`, `u8`–`u64`, `isize`, or `usize`:

- The enum gains `#[repr(rs_type)]`.
- Every variant gains `#[sea_orm(num_value = N)]`.
- A value-based `TryFrom<rs_type>` is generated with `type Error = ::sea_orm::DbErr`.
- Explicit discriminants are honored as integer literals (`A = 10, B` continues from `11`; a leading `-` is accepted).
- Duplicate values are collected as `Duplicate variant value 'N': discriminants must be unique for the generated 'TryFrom'` and the `TryFrom` is skipped.
- Non-unit variants with an integer `rs_type` report `Failed to generate TryFrom: variant 'X' has fields, only unit variants are supported with integer 'rs_type'` and skip the `TryFrom`.

String `rs_type` values instead get `#[sea_orm(string_value = "...")]` per variant, with no `TryFrom` and no `#[repr]`.

## Migration helper

`migration = true` emits `impl Enum { pub fn migration_column_def() -> ::sea_orm_migration::sea_query::ColumnDef }`. The `db_type` maps to the `ColumnDef` method through this table:

`String` → `string`, `Text` → `text`, `TinyInteger` → `tiny_integer`, `SmallInteger` → `small_integer`, `Integer` → `integer`, `BigInt` → `big_integer`, `TinyUnsigned` → `tiny_unsigned`, `SmallUnsigned` → `small_unsigned`, `Unsigned` → `unsigned`, `BigUnsigned` → `big_unsigned`, `Float` → `float`, `Double` → `double`, `Boolean` → `boolean`, `Date` → `date`, `DateTime` → `date_time`, `Json` → `json`, `JsonBinary` → `json_binary`.

An unmapped `db_type` — including parameterized values such as `"String(sea_orm::sea_query::StringLen::None)"` — reports `Failed to generate the migration helper: db_type 'X' has no 'ColumnDef' mapping`.
