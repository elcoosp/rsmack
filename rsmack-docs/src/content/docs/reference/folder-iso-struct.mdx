`folder_iso_struct` is an attribute macro — generated by `megamac!(kind = Attr, name = folder_iso_struct, doc = "readme")` — that mirrors a folder of Rust modules into a struct inline at expansion time. Crate path: `rsmack_fs` (facade: `rsmack::folder_iso_struct`, feature `fs`).

## Signature

<Code lang="rust" code={`#[folder_iso_struct(folder = "levels", vis = "pub", recursive = true, derives("Debug"))]
pub struct Levels { ... }`} />

## Arguments

### folder :badge[required]

- **Type:** string literal
- **Meaning:** folder to mirror, relative to the calling crate's `src/` — `"levels"` or `"ui/screens"`
- **Error:** a missing folder is fatal — `Failed to scan the folder to mirror '<path>': <reason>`

### vis :badge[optional]{variant="note"}

- **Type:** string literal, e.g. `"pub"` or `"pub(crate)"`
- **Default:** the annotated struct's declared visibility
- **Meaning:** visibility of every generated struct; invalid values are fatal — `Invalid 'vis' value 'X', expected e.g. 'pub' or 'pub(crate)'`

### recursive :badge[optional]{variant="note"}

- **Type:** `bool`
- **Default:** `false`
- **Meaning:** subdirectories become inline `pub mod <name>` blocks holding their own mirrored struct, named after the PascalCase of the directory; in flat mode, directories become plain fields (legacy behavior)

### derives :badge[optional]{variant="note"}

- **Type:** list of string literals, parsed as paths
- **Default:** empty
- **Meaning:** extra derives injected on every generated struct, next to the annotated struct's own attributes; invalid entries report `Invalid 'derives' entry`

## Scanning rules

- The folder `$CARGO_MANIFEST_DIR/src/<folder>` is scanned at expansion time — no build script, no `OUT_DIR` artifacts.
- Entries sort deterministically; `mod.rs` is skipped.
- Each file stem maps to a snake_case field name and a PascalCase type name: `beta_gamma.rs` → field `beta_gamma`, type `BetaGamma`. Keywords become raw idents.
- Non-UTF-8 stems are reported.

## Carry-over and references

- The annotated struct's attributes and visibility are copied onto every generated struct.
- The declared fields are a sketch only and are discarded — the folder is the source of truth.
- Mirror fields reference `crate::<folder segments>::<mod>::<Type>`, so the modules must exist in the calling crate's module tree.
- Tuple structs are fatal — `Only named struct supported`.

## Example

<Code lang="rust" code={`use rsmack_fs::folder_iso_struct;

#[folder_iso_struct(folder = "levels", vis = "pub", derives("Debug"))]
pub struct Levels {
    // The declared fields are a sketch only: the mirror is generated from the folder.
    #[expect(dead_code)]
    alpha: (),
}`} />

generates, for `src/levels/{button.rs, beta_gamma.rs}`:

<Code lang="rust" code={`#[derive(Debug)]
pub struct Levels {
    pub button: crate::levels::button::Button,
    pub beta_gamma: crate::levels::beta_gamma::BetaGamma,
}`} />
