`wrap` is an attribute macro — generated by `megamac!(kind = Attr, name = wrap, doc = "readme")` — that wraps every field of a named struct in a generic type. Crate path: `rsmack_wrap` (facade: `rsmack::wrap`, feature `wrap`).

## Signature

```rust
#[wrap(with = Option)]
struct User {
    name: String, // Option<String>
    #[wrap(skip)]
    untouched: &'static str,
}
```

## Item arguments

### with :badge[required]

- **Type:** `syn::Ident` — accepted as a bare identifier or a string literal
- **Default:** none, the argument is required
- **Meaning:** the default wrapper applied to every field without per-field configuration
- **Example:** `with = Option` or `with = "Option"`

## Per-field arguments

Parsed from each `#[wrap(...)]` attribute on a field; the attribute is consumed from the output.

### skip :badge[optional]{variant="note"}

- **Type:** `bool`
- **Default:** `false`
- **Meaning:** leaves the field type untouched

### with :badge[optional]{variant="note"}

- **Type:** `syn::Ident`
- **Default:** inherits the item-level wrapper
- **Meaning:** per-field wrapper override
- **Example:** `#[wrap(with = "Box")]`

### map :badge[optional]{variant="note"}

- **Type:** `syn::Type`
- **Default:** none — the original inner type is kept
- **Meaning:** replaces the inner type entirely
- **Example:** `#[wrap(with = "Vec", map = "u8")]` turns `String` into `Vec<u8>`

## Supported field types

The transformation parses `Wrapper<Inner>`, so every type expression wraps:

| Field type | With `Option` |
| --- | --- |
| `String` | `Option<String>` |
| `Vec<T>` | `Option<Vec<T>>` |
| `&'static str` | `Option<&'static str>` |
| `*const u8` | `Option<*const u8>` |
| `fn(u8) -> bool` | `Option<fn(u8) -> bool>` |
| `Box<dyn Send>` | `Option<Box<dyn Send>>` |
| `(u8, u16)` | `Option<(u8, u16)>` |
| `[T; N]` | `Option<[T; N]>` |

## Constraints and behavior

- Only named-field structs: tuple and unit structs are fatal — `Only named struct supported`.
- Generics and where-clauses pass through untouched; only the fields are rewritten.
- Non-`wrap` attributes are preserved. Place the macro **before** `#[derive(Serialize, Deserialize)]` so the derive observes the wrapped types.
- Broken per-field attributes are collected as `Failed to parse wrap attribute: {e}` and stripped.
