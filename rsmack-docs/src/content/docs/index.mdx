**rsmack** is a Rust proc-macro factory. You write a `pub struct Args` with doc comments and a `pub fn exec` that does the transformation; the framework handles entrypoint generation, payload-protocol selection, documentation extraction, error plumbing, and file codegen. One `cargo add rsmack` installs every shipped macro.

The workspace ships five macros and the toolkit behind them:

- [`edoc`](/reference/edoc/) — documentation from constants, with typed const-expression evaluation
- [`wrap`](/reference/wrap/) — field type wrappers that accept any type
- [`seanum`](/reference/seanum/) — `SeaORM` active enums with discriminants and migrations
- [`folder_iso_struct`](/reference/folder-iso-struct/) — inline compile-time folder mirroring
- [`megamac`](/reference/megamac/) — the signature-driven factory that generates all of the above and your own macros

Everything rests on [`rsmack-utils`](/reference/rsmack-utils/), which provides the `ExecEnv`/`Logr` diagnostics pair — a `syn::Error`-based, panic-free replacement for the abandoned `proc-macro-error2` crate.

## Requirements

- Rust **1.94 or newer** (edition 2024, pinned by `sea-orm 2`)
- A crate where you want to use or author macros
